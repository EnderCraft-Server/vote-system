# 前台视觉与交互规范

目标：一张**票面**，而不是一个"AI 生成的落地页"。所以这里没有渐变、没有 emoji 当图标、
没有紫色强调色、没有"01 / 02 / 03"装饰编号，也没有堆叠的卡片阴影。

## 两个层次

| 层次 | 内容 | 材质 |
| --- | --- | --- |
| 内容层 | 标题、题干、选项、结果条、页脚 | 不透明纸面（`--paper` / `--surface`）、发丝线分隔 |
| 功能层 | 顶部导航、底部提交条 | 毛玻璃（`backdrop-filter: blur(18px) saturate(1.4)` + 74% 填充） |

这条界线来自 Apple HIG 的 *liquid-glass* 指南：玻璃只能用在浮动的功能层，
"放在内容层会造成层级混乱"。所以卡片、题块、结果条一律不透明，只有随页面滚动、
始终浮在内容之上的导航与提交条使用玻璃；并且：

- `prefers-reduced-transparency: reduce` 时退回不透明；
- 不支持 `backdrop-filter` 的浏览器用 `@supports not` 兜底为实色；
- 玻璃上只放文字与一个主按钮，不放彩色元素（强调色留给"提交投票"）。

## 色彩

浅色（默认）：

| 变量 | 值 | 用在 | 对比度 |
| --- | --- | --- | --- |
| `--paper` | `#F6F4EF` | 页面底色（微暖的纸） | — |
| `--surface` | `#FFFDF9` | 票面卡片 | — |
| `--ink` | `#17191C` | 正文、标题 | 16.0:1 |
| `--ink-2` | `#565A60` | 简介、次要说明 | 6.3:1 |
| `--ink-3` | `#686B71` | 元信息、题号、字数 | 4.9:1 |
| `--rule` | `#DCD6C8` | 发丝线 | — |
| `--accent-solid` | `#1B3A5C` | 主按钮底 | 白字 11.6:1 |
| `--stamp` | `#A33B2E` | "已投票"印章、错误 | 5.9:1 |

深色（`prefers-color-scheme: dark`，同一套变量换值）：纸 `#14161A`、卡 `#1A1D22`、
正文 `#E9E6DF`（14.5:1）、次要 `#A9A69F`（7.5:1）、元信息 `#9A978F`（6.2:1）、
主按钮底 `#A9C6E4` + 深色字（10.3:1）。

没有"第二个强调色"：链接、按钮、结果条、焦点框全部是同一支墨蓝；朱红只用于
"已投票"和错误提示，含义唯一。

## 字体

| 用途 | 字族 | 说明 |
| --- | --- | --- |
| 标题（h1 / h2） | `--serif`：Iowan Old Style / Palatino / Georgia / Songti SC / Noto Serif CJK | 纸面感的来源；中文落到宋体系 |
| 正文、控件 | `--sans`：system-ui / PingFang SC / Microsoft YaHei | 导航与控件用系统字，符合平台惯例 |
| 元信息、题号、验证码 | `--mono` | 数字与编码用等宽，避免跳动 |

数字统一 `font-variant-numeric: tabular-nums`，统计表与结果条不会因为位数变化左右跳。

## 版面

- 单列，`max-width: 720px`；票面卡片内边距 40px（移动端 24/20px）。
- 题目按"第 1 题"的序号写在左侧窄栏里（等宽小字），题干在右——像一张真的选票。
- 选项是一整行可点的方框（不是裸 radio），选中时边框变墨蓝、底色 6% 着色；
  勾选框是自绘的（`appearance: none`），避免系统主题把未选中的框画成实心。
- 排序题用上下箭头按钮重排，纯 DOM 顺序提交；不依赖拖拽，键盘可用。
- 结果页：横条 + 数字；排序题给"平均名次 / 排第一次数"表；简答题只给份数（原文不公开）。
- 提交条固定在视口底部（玻璃），显示"提交后不可修改"的说明与唯一主按钮。

## 交互与动效

- 只做 `border-color `/` background-color ` 的 150ms 过渡；没有位移、没有缩放、没有视差。
- `prefers-reduced-motion: reduce` 时全部关掉。
- 提交失败后页面会把焦点移到错误区（`role="alert"` + `tabindex="-1"`），并给出具体原因（验证码错、已投过、已结束…），
  不是笼统的"提交失败"。
- 防重复提交：按钮点击后立即禁用 8 秒，避免双击产生两次请求。
- 提交按钮在请求期间禁用；服务端返回错误时页面重载，状态自然恢复。

## 可访问性

- 正文对比度 ≥ 4.5:1（见上表），大标题 16:1。
- 所有可交互元素有 `:focus-visible` 的 2px 描边；提供"跳到正文"链接。
- 移动端点按区域 ≥ 44×44（排序箭头与按钮在小屏单独放大）。
- 排序变化通过 `aria-live="polite"` 播报（"监控与照明 → 第 2 位"）。
- 验证码图片有 `alt` 说明，输入框 `inputmode="numeric"`。
- 必答标记用 `*` + 视觉隐藏的"（必答）"，不只靠颜色。
- 表格有 `scope="col"`，结果条图形有 `aria-label`（"中心广场：100%"）。

## 刻意避开的东西

| 常见"AI 味" | 这里的做法 |
| --- | --- |
| 紫蓝渐变、发光按钮 | 单一墨蓝实色，hover 只加深 |
| 满屏大圆角 + 阴影卡片 | 4~6px 圆角 + 1px 发丝线，几乎不用阴影 |
| emoji 当图标 | 只用文字与箭头字符（↑ ↓），没有图标字体依赖 |
| 每个区块都有小标题 + 装饰编号 | 只有真实需要序号的题目才有编号 |
| 空话文案（"让我们一起…"） | 每句都说清楚"会发生什么"：一网络一票、提交后不可改、简答原话不公开 |
| 中英混排的半角标点 | 全角中文标点，数字与英文按西文排版 |

## 语言

中文为主，英文通过 `?lang=en` 或浏览器 `Accept-Language` 切换；缺词条回退中文。
文案集中在 `frontend/app/lang/zh.php` 与 `en.php`，页面里不出现硬编码中文。
